# Security policy

Capture defaults (summaries vs opt-in raw content), export sanitization, storage and
deployment boundaries are covered in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability

Open a [security advisory](https://github.com/FishRaposo/agenttrace/security/advisories/new)
or email fishraposo@gmail.com with the subject `[agenttrace security]`. Please do
not open a public issue for a security report.

## Supported versions

Security fixes target the latest tagged release and `main`.
